1. Explain the difference between frontend, backend, and full-stack development with
suitable real-world examples.

Frontend is what users see and interact with on a website — the design, buttons, forms, etc.
Example: The homepage of Amazon — the product images, search bar, and buttons.
Backend is what happens behind the scenes — it handles data, logic, and communication with databases.
Full Stack means working on both frontend and backend.
Example: A full-stack developer could design the Amazon product page and also write the code that saves your orders to the database.

3. Describe how a browser requests and displays a web page from a web server.
 
 
    You type a web address (like www.google.com).
    The browser sends a request to the web server.
     The server finds the page and sends back files (HTML, CSS,        
     JavaScript).
    The browser renders those files — showing text, images, and   
     layout on your screen.

4. Identify and list the tools required to set up a web development environment. Explain the
purpose of each.
  VS Code – main text editor to write code.
  Web Browser (like Chrome) – to test and view your website.
  Node.js (optional) – helps run JavaScript outside a browser for backend work.
  Git – keeps track of code changes.
  Live Server (VS Code extension) – shows your webpage instantly as you edit.

5.Explain what a web server is and give examples of commonly used servers. 
A web server is a computer that stores and delivers web pages to users when they request them.
Examples: Apache, Nginx, Microsoft IIS, and LiteSpeed.

6.Define the roles of a frontend developer, backend developer, and database administrator
in a project.
* Frontend Developer: Designs how the website looks and feels.
* Backend Developer: Handles the data and logic behind the website.
* Database Administrator (DBA): Manages the storage, safety, and structure of data in the database.

Dynamic WebsiteContent changes based on user input or data.
