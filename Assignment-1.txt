3. You type a web address (like www.google.com).
         The browser sends a request to the web server.
     The server finds the page and sends back files (HTML, CSS,        
     JavaScript).
    The browser renders those files — showing text, images, and   
     layout on your screen.

4.  VS Code – main text editor to write code.
  Web Browser (like Chrome) – to test and view your website.
  Node.js (optional) – helps run JavaScript outside a browser for backend work.
  Git – keeps track of code changes.
  Live Server (VS Code extension) – shows your webpage instantly as you edit.

5. A web server is a computer that stores and delivers web pages to users when they request them.
Examples: Apache, Nginx, Microsoft IIS, and LiteSpeed.
